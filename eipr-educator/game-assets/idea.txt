# NPC Movement

Each NPC gets:

```javascript

  homeX,
  homeY,
  wanderRadius,
  speed
}
```

Example:

```javascript
Farmer
```

```javascript
{
 x:400,
 y:2400,
 wanderRadius:100,
 speed:0.5
}
```

Behavior:

```text
Walk
Stop
Turn
Walk
Talk
```

Randomized.

Looks alive.

# Prototype Build Order

We should create these files in order:

```text
1. index.html
2. style.css
3. world.js
4. player.js
5. npc.js
6. camera.js
7. quest.js
8. dialogue.js
```

For the next prompt, we should create only:

```text
index.html
```

with:

* Canvas
* Game HUD
* XP bar
* Quest tracker
* Dialogue box
* Inventory button
* Minimap placeholder

and nothing else yet.

That will give you a clean foundation before we move to player movement and world rendering.
